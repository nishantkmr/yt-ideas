# Kids Trivia Studio

Phase 2 foundation for a Remotion-powered YouTube Kids GK/trivia production system, with a shared visual system for vertical shorts and landscape episodes.

## Commands

```powershell
npm run dev
npm run typecheck
npm run build
npm run render:short
npm run render:episode
```

The two compositions currently use sample JSON. Shared color, typography, spacing, cards, progress, countdown, and answer states live in `src/styles/global.css`.
